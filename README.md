# FENIX /13 — NIGHT ENGINE

**Version 4: a new 30-second Remotion advertisement.** Procedural copper 3D
sculptures, a camera-driven light tunnel, kinetic typography, extruded word
sculptures, and a cinematic FENIX /13 assembly with a moving light conductor.
Original clean electronic music, bass impacts, movement effects, and a bespoke
brand motif. No footage, photographs, characters, voiceover, or noise bed.

1080 × 1920 • 9:16 • 30 fps • H.264 • AAC 48 kHz stereo.
